## How the image was made

The v1 image (1024×1024, PNG, 182,517 bytes) was rendered programmatically with Python PIL from the 40 verified stories — no photographs, no copied artwork. The layout is a real front page: nameplate with the date set large, a hero lead with a drawn court scene (courthouse facade, columns, scales of justice), two second stories with line illustrations (three summit flags, broken bridge), then the breadth grid — three columns, seven section headers with small gold glyphs, headline-only items each with a drawn pictogram — plus 25 briefs, a UTC timeline strip, a markets strip, and a date-check footer. Text fitting is enforced in the renderer: every headline and sub is wrapped to a measured budget and the build fails rather than letting text overlap or run off. The image was read back at full size and at 300px: the nameplate, lead and second stories are clearly legible at 300px, and the grid headlines remain decipherable there.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Python 3.13, standard library only, no dependencies, no network. `main.py` copies `entry.png` beside it to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output/entry.png`). Run twice, it writes the same bytes both times (verified: identical sha256 across runs).
